# AdAce Ads plugin for Claude

This repository is a Claude plugin marketplace with one plugin, `adace-ads`, in the folder `adace-ads/`.

The plugin connects Claude to your ad accounts through the hosted AdAce Ads connector (https://ads.adace.website/mcp) and adds skills for performance reviews, finding wasted spend and making changes that you approve.

Details: [adace-ads/README.md](adace-ads/README.md). Website: https://ads.adace.website
